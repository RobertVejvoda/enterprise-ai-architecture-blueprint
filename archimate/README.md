# ArchiMate

This directory contains governed architecture views and modelling guidance for the blueprint.

## Purpose

ArchiMate is the primary modelling language used to describe motivation, strategy, business, application, technology, and implementation and migration concerns.

## Planned View Areas

- motivation;
- capability map;
- value streams;
- business architecture;
- application architecture;
- technology architecture;
- implementation and migration;
- model exchange artefacts.

Additional subdirectories will be added only when the first governed view for that area is introduced.

## Modelling Principles

- Model a clear stakeholder concern or architecture question.
- Use logical and functional names rather than vendor or product names.
- Keep viewpoints focused; do not place the entire architecture into one diagram.
- Maintain consistency between diagrams and their explanatory text.
- Preserve editable source and an accessible rendered format for every governed diagram.

## Boundaries

ArchiMate files express architecture views. Narrative method guidance belongs in [`../togaf/`](../togaf/), while detailed reusable structures belong in [`../reference-architecture/`](../reference-architecture/) and [`../patterns/`](../patterns/).

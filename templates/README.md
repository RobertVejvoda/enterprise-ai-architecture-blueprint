# Templates

This directory contains lightweight templates for repeatable architecture and governance work.

## Purpose

Templates provide a consistent starting point without forcing every architecture problem into the same document structure. They should improve completeness and reviewability while remaining adaptable.

## Initial Template Candidates

- architecture definition;
- AI use-case assessment;
- solution concept;
- architecture decision record;
- control assessment;
- implementation conformance review.

Template files will be introduced only when there is a concrete use case for them.

## Template Principles

- Keep required fields minimal.
- Explain the purpose of each section.
- Separate facts, assumptions, decisions, risks, and open questions.
- Include traceability to stakeholder concerns, architecture artefacts, and controls where relevant.
- Avoid product-specific terminology and unnecessary process ceremony.

## Boundaries

Templates support the rest of the repository; they do not define architecture policy by themselves. Stable rules belong in the relevant TOGAF, ArchiMate, reference architecture, controls, or compliance artefacts.
